# NovaRetail Collaboration Tools and Peripherals

## Video Conferencing
NovaRetail uses the company-licensed meeting platform for video calls. If your camera or microphone is not detected, check the app's device settings, confirm the operating system has granted permission, and restart the app. Conference room systems can be reset using the power button on the control panel.

## Printing
Printers are available on each floor and are added through the Software Portal's printer package. If a print job is stuck, cancel it, restart the print spooler by logging out and back in, and try again. Secure print requires a badge tap at the printer. For toner or paper jams, contact Facilities.

## File Sharing and Cloud Storage
Team files should be stored in the approved cloud storage service, not on local drives. External sharing requires a link with an expiry date, and Restricted data must not be shared externally. Deleted files can be recovered from the recycle bin for 93 days.

## Mobile Devices
Employees may access email on personal phones only after enrolling in mobile device management, which allows IT to remotely wipe company data. Company-issued phones must be reported immediately if lost, using the same process as a lost laptop.

## Monitors and Accessories
Employees may request one additional monitor, keyboard, and mouse through the Software Portal's hardware catalog. Ergonomic equipment requests are handled by Facilities with a manager's approval.

## Backup and Data Recovery
Cloud storage and email are backed up automatically. Local files on laptops are not backed up. If you accidentally delete a file or mailbox item, contact the IT Service Desk within 30 days to request recovery.
